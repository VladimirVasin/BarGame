Музыкальная тема супермаркета должна иметь базовое имя supermarket_theme.
Текущий файл и точный путь:
Assets/Resources/Audio/SupermarketMusic/supermarket_theme.mp3

Также поддерживаются OGG и WAV. Расширение в коде не указывается. В папке
должен находиться только один аудиофайл с базовым именем supermarket_theme.
Для бесшовной петли подготовьте начало и конец файла без паузы.

Трек плавно появляется при входе в SupermarketInterior, играет в петле только
в этой сцене и плавно затихает перед активацией следующей сцены. При замене
OGG предпочтителен для бесшовной петли. Отсутствие файла безопасно:
супермаркет остаётся играбельным без музыки.

Рекомендуемые настройки импорта в Unity:
- Load Type: Streaming
- Load In Background: включено
- Preload Audio Data: выключено
