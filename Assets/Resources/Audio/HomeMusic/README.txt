Положите сюда фоновую композицию квартиры с именем home_theme
в формате OGG, WAV или MP3.

Ожидаемый путь, например:
Assets/Resources/Audio/HomeMusic/home_theme.ogg

Расширение в коде не указывается. Для бесшовной петли подготовьте начало
и конец самого файла без паузы.

Трек играет только в HomeInterior. При выходе на балкон он плавно
затихает и ставится на паузу. После возвращения в квартиру воспроизведение
продолжается с того же места через плавное появление. Отсутствие файла
безопасно: квартира остаётся играбельной без музыки.

Рекомендуемые настройки импорта в Unity:
- Load Type: Streaming
- Load In Background: включено
- Preload Audio Data: выключено
