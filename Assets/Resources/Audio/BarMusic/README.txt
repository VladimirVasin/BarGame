Положите сюда барную тему с именем bar_theme в формате WAV, OGG или MP3.

Трек автоматически запускается при входе в сцену BarInterior, играет в петле
только в этой сцене и останавливается при Single-переходе в City.

Городская тема city_theme должна находиться только в соседней папке CityMusic.
Для бесшовной петли начало и конец самого файла должны быть подготовлены
без паузы.
