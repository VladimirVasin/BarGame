Папка для музыкальной темы потустороннего склада в CombatTest.

Добавьте один файл warehouse_theme.mp3, warehouse_theme.ogg или warehouse_theme.wav.
Например: Assets/Resources/Audio/CombatWarehouseMusic/warehouse_theme.ogg
Оставьте только один трек с этим именем; расширение в коде не указывается.

Тема автоматически загружается при следующем входе на склад и играет в петле.
Скорость воспроизведения — 80% исходной; тон также становится ниже.
Профиль CombatWarehouse в общем микшере добавляет сильное эхо и реверберацию.
Сброс боя и «Новый склад» сохраняют текущую позицию трека. При выходе тема
плавно затихает через общий MusicMix; меню паузы приостанавливает весь звук.
Пустая папка допустима: до добавления файла музыкальный слот тихий.

Unity импортирует тему как Streaming с фоновой загрузкой и сохраняет стерео.
Используется общая громкость Music; начальный trim — стандартный 0.40.
Для бесшовной петли подготовьте начало и конец файла без паузы.
