Primary intended flow:

```text
seed -> layout data -> validation -> world builder
             -> districts + central park -> district-specific world
             -> indexed street/park navigation -> player
             -> weighted route planner -> district-aware city map
             -> street perimeter -> bar/park-gate-aware chunked fences
             -> night fixture plan -> chunked lamps + signals
player + lamp anchors -> bounded light pool -> light halos
player + seed -> player-following local fog field
player -> interaction -> activity-aware scene transition <-> session state
                    -> DoorTransition scene -> preloaded destination
                    -> home layout plan -> validation -> runtime home world
                                       -> bathroom + collider-free dressing
                                       -> two authored shots + hold hysteresis
                                          + opt-in exact billboard plane/aspect
                                       -> open-side bed trigger
                                          -> E: lie -> persistent sleep -> wake
                                          -> reusable animated interaction
                                             + motor/rig/shadow restoration
                                             + projected bed axis / handedness
                                       -> two aligned Light/emitter/halo pairs
                                          + grade + dust + Home loop
                                       -> exit -> home return kind -> City
                    -> bar layout plan -> validation -> runtime world
                                       -> clear routes + activity fixture
                                       -> six practical lights + local grade
                                       -> 12-NPC crowd + spatial soundscape
                                       -> skippable single-camera reveal
                    -> generic bar station -> minigame catalog
                                           -> cocktail rules/offers
                                           or beer-pong physics/session
                                           or Split the G timer/scoring/session
                                           or tincture board/cascades/XXX
                                           -> drinking progress -> session state
                                           -> completed visit -> city map
                    -> counter station -> nine-item drink shop
                                       -> atomic cash + drinking transaction
session intoxication -> five-stage profile -> motor + puppet + camera
                                      -> PS1 world distortion
                                      -> above 60 -> deterministic balance QTE
                                         -> success or visual fall/recovery
F9 -> close conflicting modal -> session intoxication +/-20
                              -> minigame catalog -> isolated debug instance
F8 -> structured state snapshot -> immediate debug.log flush
session/scene/gameplay result boundaries -> correlated rotating debug.log
scene root -> matching scene-local music player -> Single transition stops it
           -> matching procedural ambience player
gameplay/UI events -> RetroAudioService -> bounded category source pools
URP post-processing -> averaged low-resolution image -> subtle RGB555 blend -> point upscale
world composite -> crisp retro IMGUI overlay
```
